# Freelance Marketplace

A mini Upwork-inspired freelance marketplace built with Django and Tailwind CSS.

## Features

- User Authentication
- Freelancer Profiles
- Client Profiles
- Job Posting
- Proposal Submission
- Dashboard

## Tech Stack

- Django
- Tailwind CSS
- SQLite
- Git & GitHub
